# Travelling Salesman Problem (TSP)

##  Overview
This project explains the Travelling Salesman Problem using:
- Genetic Algorithm (GA)
- Ant Colony Optimization (ACO)

##  Genetic Algorithm
- Inspired by natural selection
- Uses population, crossover, mutation
- Finds near-optimal solutions

##  Ant Colony Optimization
- Inspired by ants and pheromones
- Efficient for shortest path problems
- Faster convergence than GA

##  Comparison
- GA → General optimization
- ACO → Best for path problems like TSP
